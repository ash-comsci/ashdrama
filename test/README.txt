Option 2: navigation, playbill opening, animated lights and gold season strip.
Option 1: side-by-side production cards, silver About section and compact footer.

PREVIEW: Extract the ZIP, then open index.html in a browser.

UPLOAD: Back up your current version. Upload the extracted index.html, css folder, js folder and images folder to your GitHub repository root. Do not upload the ZIP or an enclosing folder. Keep CNAME containing ashdrama.ca. This package includes that CNAME and .nojekyll. No DNS changes are required.

EDIT LINKS: Open js/main.js. In settings.shows, enter each show's full ticket URL in tickets: '' and its photo album URL in pictures: ''. Keep the surrounding quotes and commas. Fill contactEmail with your school contact email. Ticket and photo URLs are blank because none have been provided yet.

EDIT CONTENT: index.html holds the card headings, dates and descriptions. Info dialog text is in settings.shows in js/main.js. Edit css/style.css for colours, layout and animation. All image files are in images/; the supplied logo is unchanged and no images are embedded in code.

Past Productions and Gallery open coming-soon panels until real content is supplied. Contact opens a placeholder until contactEmail is filled. Mobile menu, accessible dialogs, lighting pause and reduced-motion support are included.
